## The six decisions

**⬛ 1. The +10 adaptation bonus — keep, change, or drop?**
In Operating Systems every student examined through the system received +10, as compensation for
being the first cohort to use it. It is a course policy, not a system feature. If you keep it, it
is applied to everyone automatically; if you drop it, the final grade is simply the weighted
average. Note it materially changes the grade distribution.

**⬛ 2. The survey link.** The OS email links a mandatory post-exam AI survey. Do you want one? If
yes we need the URL; if no we remove the whole section. Currently the text calls it a course
requirement — only keep that phrasing if it is one.

**⬛ 3. "איכות הפתרון הכתוב" — is that what you would call it?**
The OS version said "איכות הקוד". We changed it to refer to the written solution. This label
appears twice and is what students will argue with you about, so pick the term you would use in a
tutorial.

**⬛ 4. The retake sentence.** The OS course lets a dissatisfied student request another sitting
by contacting staff. Is that your policy? It sets an expectation the moment it is written down.

**⬛ 5. Is 75% / 25% right for this course?** It is in your profile already, and this email states
it explicitly to students. Worth a second look now that you can see how it reads: a student whose
written solution is strong but who cannot defend it orally is capped fairly low.
